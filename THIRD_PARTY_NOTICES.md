## Optional NVIDIA runtime

When CUDA is selected, AIR3view can download the official NVIDIA `nvidia-cublas-cu12==12.8.4.1` Windows wheel from PyPI, checked against a pinned SHA256. These proprietary runtime libraries are installed separately in the user's AIR3view data directory, with the wheel's license files. They are not part of the AIR3view ZIP or its open source license. CTranslate2 4.8.3's Windows wheel is built without cuDNN; this optional runtime does not install cuDNN or an NVIDIA display driver.
